# Physical Computing Project 2026 - IT KMITL
## Raberd-Wela-AHHHHH

### Description
  "Raberd-Wela-AHHHHH" คือ Game Development เป็นเกมที่ผู้เล่น 4 คน ผลัดกันแก้ปัญหาคณิตศาสตร์ ภายในเวลาที่กำหนด ถ้าผู้เล่นตอบถูกภายในเวลาที่กำหนด ระเบิดจะถูกส่งให้ผู้เล่นคนถัดไป แต่ถ้า ตอบไม่ทันภายในเวลาที่กำหนด ผู้เล่นจะถูกนำออกจากการแข่งขัน

### Purpose
  ในปัจจุบัน การฝึกฝนทักษะการคิดเลขในใจมักทำผ่านแบบฝึกหัดหรือแอปพลิเคชันทั่วไป ซึ่งมักมีความจำเจและขาดปฏิสัมพันธ์ระหว่างผู้เล่น โปรเจกต์นี้จึงต่อยอดแนวคิดมาจากเกมแนวส่งระเบิดที่มีชื่อเสียง เช่น Bomb Party (เกมบนเว็บที่ใช้การพิมพ์คำศัพท์) และ Pass the Bomb (บอร์ดเกมจับเวลา) โดยนำมาพัฒนาให้อยู่ในรูปแบบของอุปกรณ์ฮาร์ดแวร์จริง และเปลี่ยนภารกิจจากการพิมพ์คำศัพท์เป็นการแก้สมการคณิตศาสตร์ เพื่อเปลี่ยนการเรียนรู้และฝึกสมองให้กลายเป็นกิจกรรมสันทนาการที่สนุกสนาน
